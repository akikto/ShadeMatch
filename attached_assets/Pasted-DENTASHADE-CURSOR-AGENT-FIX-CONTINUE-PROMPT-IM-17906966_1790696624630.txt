1. PRODUCT
================================================

App name:

DentaShade

Purpose:

A mobile dental shade-assistance application.

The app photographs a patient's tooth using a smartphone camera, processes the image through a controlled color-science pipeline, compares the measured tooth color against VITA Classical A1–D4 reference data, presents the closest candidates, allows dentist confirmation/override, and generates a dental laboratory report PDF.

Platforms:

- Android
- iPhone/iOS

IMPORTANT:

This is a SHADE-ASSISTANCE system.

Do NOT claim:

- spectrophotometer equivalence
- clinical validation unless actually completed
- certified clinical accuracy
- fake confidence percentages
- unsupported VITA reference accuracy
